## Changes from the plan (recorded)

- **App Attest moved to M10** (ADR 0006): it needs real-device data to verify correctly.
- **Account purge and audit-partition creation run as CLI/manual jobs** until the `worker`
  process exists. Schedule `accounts:purge` daily (cron/systemd timer) in any deployed environment.
- **Server bans** and **community-server owner registration** are not part of M2; they arrive with
  moderation (M7) and community servers (M8). Join tickets already carry everything needed.
- Ticket `jti` values are random UUIDv4 (any unique string is allowed by the spec).

## Try it locally

```bash
pnpm install && pnpm infra:up && cp .env.example .env && pnpm db:migrate
pnpm dev                                                  # API on :8080
pnpm --filter @kindling/api staff:invite -- --email you@studio.example --name You --role super_admin
# Then: POST /admin/v1/auth/setup/begin {token} → add the secret to an authenticator app →
#       POST /admin/v1/auth/setup/complete → POST /admin/v1/auth/login → POST /admin/v1/servers
pnpm --filter @kindling/api fake-server -- --token <kst_… from the previous step>
```
